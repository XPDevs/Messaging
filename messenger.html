    How it works

    Your 6-digit code is a topic on ntfy.sh. Share it and any message sent to that topic appears here live. Add a chat with another device's code to talk on a different topic.

    Photos — tap the image button, or paste/drag an image in. Images are downsized and uploaded to ntfy, shown inline, and saved locally so they stay even after ntfy expires them (~3h). Tap an image to open it or save it.

    Vault Lock 🔒 — arm the lock, then send. Your message (or photo) is encrypted on your device with a passcode before it ever reaches ntfy. Anyone with the code still sees only ciphertext; the recipient needs the passcode to read it. Message text and photos are both supported.
